# AI Resume & Job Description Analyzer

## About the Project
This is a web application that helps job seekers compare their resume with a job description. It identifies matching and missing skills and gives suggestions to improve the resume.

## Features
- User registration and login
- Resume and job description analysis
- Resume match percentage
- Matched and missing skills
- Resume improvement suggestions
- Interview question suggestions
- View and manage previous analyses
- Local skill-matching fallback when the Gemini API is unavailable

## Technologies Used
- **Backend:** PHP, Laravel
- **Database:** MySQL
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **API:** REST API
- **AI integration:** Gemini API with a local fallback

## How It Works
1. Register or log in to the application.
2. Enter your resume text and the job description.
3. Click **Analyze**.
4. View the match percentage, skills, and suggestions.
5. View previous analyses in the history section.
